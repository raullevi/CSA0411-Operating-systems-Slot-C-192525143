## How to Execute the Lab Experiments
To compile and run any C program or execute a shell script:
```bash
# To execute a specific shell experiment (e.g. Exp 02):
cd "Lab Experiments/Exp02_System_Info_Resource_Monitoring"
./script.sh

# To compile and run a C experiment (e.g. Exp 20 - FCFS):
cd "Lab Experiments/Exp20_FCFS_CPU_Scheduling"
gcc main.c -o exp20
./exp20 < input.txt
```

## Automated Master Execution Harness
A master script `run_all_experiments.sh` is provided in this folder to run all 40 experiments sequentially:
```bash
chmod +x run_all_experiments.sh
./run_all_experiments.sh
```
